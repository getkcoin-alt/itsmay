Guide

How to use Scrappy

Scrappy is an orchestrator. You talk in plain language; he runs a multi-turn loop — calling tools, delegating to experts, spawning terminal workers — until he has an answer. You don't manage any of that.

Experts

  • Memory Keeper — saves and recalls durable facts. "Remember I use Stripe for payouts" or "What do you know about my stack?"
  • Strategist — high-leverage business / architecture calls. Picks and ranks, no fence-sitting.
  • Email — reads, summarises, drafts, sends Gmail (needs Gmail connector). Drafts by default — only sends when you say "send it".

Terminal Agents

Scrappy can spawn autonomous Claude workers with bash access. Just describe the outcome:

  • "Write a Python CSV-to-JSON converter and run it" → one agent
  • "Do these three things in parallel" → three agents simultaneously
  • "Build it, test it, fix any errors" → Scrappy chains agents on the results

Watch live in the Agents tab — every command and output is logged.

Memory

Every conversation is embedded and stored; relevant bits are recalled automatically on future turns. Browse, search by meaning, add, or delete in the Memory tab. Importance (0–1) biases recall — identity/goals high, trivia low.

Browser Watch

Scrappy monitors Chrome tabs for changes via AppleScript — no extension required. In the Watch tab, describe what to monitor; he lists your tabs, you pick one, the watcher runs every 2 minutes and reports here. Runs via the Mac voice agent (python -m apps.mac_agent.voice_loop).

Tips

  • One complete message beats a chain of fragments — experts get a self-contained task brief, not the full thread.
  • The inline → tool / ✓ result chips show exactly what Scrappy did.
  • New session in Chat clears context. Use it when switching topics.
  • The System tab shows which connectors and experts are live.
