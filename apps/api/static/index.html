How to use Scrappy

Scrappy is an orchestrator. You talk to him in plain language; under the hood he runs a multi-turn loop where he can call tools, hand work to specialist experts, read the result, and keep going until he can answer. You don't manage any of that — you just ask.

The crew (experts)

  • Memory Keeper — remembers durable facts and recalls them later. Say "remember that I use Stripe for payouts" or "what do you know about my payment setup?"
  • Strategist — high-leverage business / architecture calls. Say "should I build the API or the UI first?" — it ranks and picks, no fence-sitting.
  • Email — reads, summarises, drafts, and sends Gmail (only when the Gmail connector is wired). It drafts by default and only sends when you explicitly say "send it".

An expert only appears once the connectors it needs are installed — check the System tab to see who's live right now.

Memory

Every conversation is embedded and stored; relevant bits are pulled back automatically on future turns. The Memory tab lets you browse what's stored, search it by meaning, hand-add a fact, or delete something. Importance (0–1) biases what gets recalled — identity/goals high, trivia low.

Browser Watch

Scrappy can monitor any open Chrome tab for changes. When the content changes, he analyses the diff, sends you a macOS notification, and logs the summary in the Watch tab here.

  • Go to the Watch tab and type what you want him to monitor — e.g. "keep an eye on my Stripe dashboard".
  • Scrappy lists your open tabs, you pick one, and the watcher starts (every 2 minutes by default).
  • Or say it in the Voice loop — same flow.
  • To stop: say "stop watching" in Chat or Voice.

The watcher runs locally on your Mac via the voice agent (python -m apps.mac_agent.voice_loop). It needs Chrome open — no extension required.

Voice vs. web

This console talks over the same brain as the Mac push-to-talk client. Mac-control tools (open apps, notify, speak, browser watch) only show up on the voice channel — here you get chat, memory, browser watch shortcuts, and expert delegation.

Tips

  • Give context in one message — experts can't see the whole thread, so Scrappy hands them a self-contained task.
  • Hit New in Chat to start a clean session.
  • Watching the inline → tool / ✓ result chips tells you exactly what Scrappy did to answer.
  • The System tab shows which connectors and experts are live — if an expert is missing, it means its connector isn't installed.
